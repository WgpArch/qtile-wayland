## ✨ Features
- **Custom Waybar Bridge:** Pipes Qtile workspace data to Waybar via a temp file and Unix signals.
- **12 Layouts:** Monad, BSP, TreeTab, Matrix, and more.
- **Cyan Accent Theme:** Cohesive `#00ffff` theming across all elements.
- **Credits:** Waybar bridge logic inspired by [stefur](https://github.com/stefur/qtile-config), Rofi menus adapted from [ahmad-shaban](https://github.com/ahmad-shaban/qtile).
