    ⌨️ Keybinds

    Qtile uses Python-based keybindings. The main modifier is mod4 (Super/Windows key).

    🖥️ Programs & System

    Keybind Action
    Mod + Return Open Terminal (st)
    Mod + W Open Firefox
    Mod + E Open File Manager (nautilus)
    Mod + A Open Rofi App Launcher
    Mod + R Open Qtile Run Prompt
    Mod + Q Kill focused window
    Mod + X Lock Screen
    Print Fullscreen Screenshot (with notification)
    Mod + Ctrl + R Restart Qtile
    Mod + Ctrl + Q Quit Qtile

    🔍 Focus & Movement

    Keybind Action
    Mod + H / L / J / K Focus Left / Right / Down / Up
    Mod + Arrows Focus Left / Right / Down / Up
    Alt + Tab Next Window
    Alt + Shift + Tab Previous Window

    📐 Window & Layout Control

    Keybind Action
    Mod + Shift + H/L/J/K Move window Left/Right/Down/Up
    Mod + Ctrl + H/L/J/K Grow window Left/Right/Down/Up
    Mod + M Toggle Maximize
    Mod + F Toggle Fullscreen
    Mod + Shift + F Toggle Floating
    Mod + Tab Next Layout
    Mod + Shift + Tab Previous Layout
    Mod + N Reset window sizes (Normalize)
    Mod + Shift + Return Toggle split

    🗂️ Workspaces (Groups)

    Keybind Action
    Mod + [1-9] Switch to workspace 1-9
    Mod + 0 Switch to workspace 10
    Mod + Minus Switch to workspace 11
    Mod + Shift + [1-9, 0, Minus] Move window to workspace
    Mod + Page Up/Down Cycle prev/next workspace
    Mod + Home / End Jump to first / last workspace
    Mod + Escape Toggle last visited workspace

    🔊 Media Keys

    Keybind Action
    Volume Up/Down Volume 5% +/- (amixer)
    Mute Toggle Master Mute
    Brightness Up/Down Backlight 5% +/- (brightnessctl)
